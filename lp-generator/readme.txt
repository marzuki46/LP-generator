Generate a complete TOFU/MOFU/BOFU funnel — landing page plus supporting articles — from one offer campaign using 9Router AI, then push new URLs to PuSH and IndexNow 10 seconds after publishing.

== Description ==

LP Generator turns a single offer campaign into a full content funnel:

* 1 Landing Page (BOFU) for a product, service, or affiliate offer.
* N MOFU articles and M TOFU articles, with topics also generated by AI.
* Contextual internal links: MOFU → BOFU, TOFU → MOFU/BOFU.
* Content generated one-by-one, sequentially, through 9Router with multi-model fallback.
* Review screen before publishing.
* After each publish, a 10-second delay then Google PuSH + IndexNow submission.
* 12 copywriting frameworks: AIDA, PAS, BAB, FAB, QUEST, DAGMAR, DIPADA, IDEPA, ACCA, AISAS, 4P, SPIN, plus custom presets.
* Amazon affiliate products and images via Bing Images `site:amazon.{region}` + affiliate deeplink (no PA-API required).
* AI-generated keyword entities, related tags (max 3), and dedicated tag articles with flexible schedules.
* Indonesian or English content per campaign, with Yoast focus keyword and SEO meta templates using campaign data (e.g. phone number).
* Optional auto-publish and configurable post scheduling (immediate, interval, fixed start, daily).
* Keyword-based image galleries on every LP/article: upload, 9Router AI image generation, or Bing Images, converted to WebP under 100 KB with WordPress + IPTC metadata.
* AI-generated campaign framework with per-section image roles and hints for fully AI-decided content/image placement.
* Interactive Activity Log with progress notes, filters, stats, and safe log deletion.
* Tabbed settings and one-click GitHub-powered plugin updates from the Plugins screen.

Google PuSH accelerates feed discovery; IndexNow is the official push API for participating engines. This plugin does not claim guaranteed instant Google indexing.

== Installation ==

1. Upload the `lp-generator` folder to `/wp-content/plugins/`.
2. Activate the plugin.
3. Go to LP Generator → Settings and fill in the 9Router Base URL, API key, and model chain.
4. Go to LP Generator → Settings → Indexing and set the IndexNow key (create the key file at your site root).
5. Create a campaign under LP Generator → Campaigns → Add New, then click Start generation.

== Frequently Asked Questions ==

= Does it work without a 9Router instance? =

No. You need a reachable 9Router base URL and a valid key. Any OpenAI-compatible endpoint exposed through 9Router works.

= Why is there a 10-second delay before indexing? =

The requested behavior is to let the post settle and permalink become available before submitting the URL. The delay is configurable per campaign and globally.

= Does this guarantee instant indexing in Google? =

No. Google has no public URL push API for ordinary pages. PuSH notifies feed hubs; IndexNow covers participating engines. Use Search Console manually for Google priority.
