# LP Generator 2.0.2 — Release Notes

Tag: `v2.0.2` · Package: `lp-generator-2.0.2.zip`

Patch perbaikan tampilan landing page setelah pengujian di WordPress lokal (WordPress 7.1.5 + GeneratePress + Yoast 28.9).

## Fixed

- Judul di hero dan area kontak berlatar gelap awalnya memakai warna teks gelap, sehingga hampir tidak terbaca. Sekarang ditimpa menjadi putih, dengan eyebrow/intro yang lebih terang.
- `.lpgen-canvas__main` mengalami horizontal scroll karena `width:100%` ditambah padding. Sekarang memakai `box-sizing:border-box`.
- Label internal **Split Proof** disembunyikan pada konten lama yang masih tersimpan.
- Kicker **TOFU / MOFU / TAG** pada related card lama diganti tampilannya menjadi **Panduan** (atau **Guide** untuk `html lang="en"`).

Catatan: untuk konten baru, label tersebut sudah benar sejak generate. Patch ini membuat konten lama yang sudah publish tetap rapi tanpa harus regenerate.
