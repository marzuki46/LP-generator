# LP Generator 2.0.1 — Release Notes

Tag: `v2.0.1` · Package: `lp-generator-2.0.1.zip`

Patch kecil untuk pengalaman admin, khususnya layar Review.

## Changed

- Redesign halaman **Review**:
  - hero dengan pemilih campaign,
  - 6 kartu statistik (total, siap review, disetujui, terbit, perlu perhatian, skor kualitas),
  - toolbar status dan aksi yang dikelompokkan,
  - tabel item dengan stage chip, status/workflow/quality yang lebih jelas,
  - empty state saat campaign belum dipilih.
- Responsive: pada lebar ≤900px tabel berubah menjadi kartu dengan label field per baris.
- Dark mode WP Admin dan focus-visible didukung.

## Fixed

- Skor kualitas tidak tampil di Review karena meta key diberi prefix `_lpgen_` dua kali. Sekarang dibaca langsung dari `_lpgen_v2_quality`.
