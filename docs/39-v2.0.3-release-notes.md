# LP Generator 2.0.3 — Release Notes

Tag: `v2.0.3` · Package: `lp-generator-2.0.3.zip`

Dua perbaikan utama: publish path conflict dan penyusunan ulang AIDA service landing page.

## Fixed — publish

**Gejala:** `Path LP sudah digunakan. Pilih mode BOFU yang sudah ada.` saat publish JOGO Jakarta, retry 2× gagal, artikel menunggu LP sampai 3/3.

`Publisher::publish_item()` sekarang memeriksa owner halaman:

- Halaman dengan path sama dan `campaign_id` sama (atau sudah terhubung ke item tersebut) → **dipakai ulang**, retry tidak error.
- Halaman dengan path sama milik campaign lain → tetap ditolak dengan pesan yang jelas.

Artikel yang menunggu otomatis dilepas setelah LP berhasil terbit.

## Changed — AIDA service LP

- Price bar `MULAI DARI / Rp 800.000` tidak dirender lagi di bagian atas.
- Harga pindah ke **kartu investasi** setelah tahap Action, bersama benefit, garansi, dan CTA.
- Sticky navigation dengan anchor: Kebutuhan, Solusi, Harga & investasi, FAQ, Hubungi kami.
- Breadcrumb: Beranda / Layanan / Website / Kota.
- Hero dua kolom dengan **sticky proof rail**.
- Benefit cards tiga kolom, price card dua kolom, footer empat kolom.
- Gambar konten: `loading="lazy"` + `decoding="async"`.

Template non-AIDA dan tipe lain tidak berubah.
