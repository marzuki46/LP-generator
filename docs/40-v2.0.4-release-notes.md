# LP Generator 2.0.4 — Release Notes

Tag: `v2.0.4` · Package: `lp-generator-2.0.4.zip`

## Menu atas (AIDA service)

Menu sekarang: **Home · Blog · Jasa · Contact Us · About Us**.

- **Home** → root domain.
- **Blog** → otomatis `home_url('/?s=' . keyword . ' ' . city)`, sehingga berisi support content untuk target keyword di kota itu. Bisa dioverride lewat field `blog_url`.
- **Jasa** → LP wilayah: `bofu_path` bila diisi, jika tidak `/jasa/website/<city>/`.
- **Contact Us / About Us** → halaman root domain (`/contact/`, `/about-us/`) karena bersifat kepercayaan situs, bukan artikel turunan keyword. Bisa dioverride per campaign lewat `contact_url` dan `about_url`.

Breadcrumb tetap: Beranda / Layanan / Website / Kota.

## Kartu harga

- Form campaign punya repeater **2–4 paket**: nama, harga, deskripsi, fitur (satu per baris), badge.
- Tombol tambah/hapus dengan batas minimal 2 dan maksimal 4.
- Render sebagai kartu perbandingan; paket dengan badge tampil sebagai paket unggulan.
- Jika semua paket kosong, plugin memakai field `price` lama sebagai satu kartu.

## Footer & area

- Area layanan tampil menurun, satu baris per area, tanpa koma.
- Footer kolom pertama berisi paragraf penjelas singkat tentang penawaran.

## Rekomendasi AI

`suggest-campaign` sekarang mengisi juga: `offer_type`, `lp_type`, `city`, `cta`, `voice`, `guarantee`, `bonus`, `price`, dan `price_tiers`, selain field yang sudah ada. Harga rekaan tidak dihasilkan bila tidak diketahui.

## CSS

Form campaign dan repeater harga memakai class `.lpgen-field-grid`, `.lpgen-price-tiers`, `.lpgen-tier-row`, `.lpgen-tier-actions`, dan `.lpgen-form-section` dengan styling di `admin/css/admin.css`.
